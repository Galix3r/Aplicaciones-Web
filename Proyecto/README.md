# Los Mejores DJs del Mundo

Proyecto web académico desarrollado para la materia de Desarrollo Web. Hice una pagina ce  información sobre los productores y DJs más influyentes de la música electrónica.

## Tecnologías Utilizadas

* **HTML5**: Estructura semántica (`header`, `nav`, `main`, `section`, `article`, `footer`).
* **CSS3**: Maquetación responsiva con Flexbox, tipografía externa (*Google Fonts - Montserrat*) y unidades relativas (`rem`).
* **Git & GitHub**: Control de versiones mediante ramas, commits bajo convenciones y despliegue continuo con GitHub Pages.
